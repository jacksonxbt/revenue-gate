# Frontend brief

Build an original Revenue Gate interface for one AI research service and its OpenFour launch milestone. Reference [OpenFour Boost](https://github.com/four-meme-community/openfour-boost-launchpad) (Next.js, wallet and launch UI patterns) and [OpenFour docs](https://github.com/four-meme-community/openfour-docs) (supported integration concepts and frontend resources). Preserve upstream licenses if reusing code. Do not assume access to partner credentials or deploy the entire Boost stack.

## Screens
- Discover: product purpose, service capabilities, milestone and testnet label.
- Research: asset input, price in test funds, payment status, sourced report and transaction reference.
- Launch: observed payments, assessment status, milestone progress and actual OpenFour state. Clearly distinguish informational eligibility from verified on-chain enforcement.

## Integration
Technical lead will provide API contract, deployment URL, payment and report response formats, supported network and contract references. Develop UI against an isolated, clearly labeled demonstration adapter until those interfaces are available. Never present mock records as real. Keep secrets server-side. Only use testnet; no autonomous trading.

## Collaboration
Use a frontend branch and pull request. Do not modify the technical lead's backend or contracts. Record open questions, evidence and blockers in GitHub.
